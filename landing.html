How it works

1
Your agent runs and finishes At the end of a scheduled run, the agent writes a small JSON file to a local inbox folder on your machine.
2
Station picks it up A lightweight local server reads the inbox folder and displays the entries in a clean list, sorted by urgency.
3
You see what needs your attention Tick items off when done, open the full brief the agent wrote, or copy a pre-filled message to continue the conversation in your AI tool.

Install in 30 seconds

Clone the repo and run the setup script. That's it — no dependencies to install, no accounts, no config files to fiddle with.

# clone and run
git clone https://github.com/catrindonnelly/station.git
cd station
bash setup.sh

# Station opens at localhost:2626
# Install as a desktop widget via Chrome menu → More tools → Create shortcut

Station registers as a macOS LaunchAgent so it restarts automatically each time you log in. To uninstall, two commands and it's gone.

What it is (and isn't)

Station is a small, opinionated tool. It does one thing and tries to do it well.

Local only
Everything runs on your machine. No cloud, no accounts, no data leaving your computer.
No database
Inbox entries are just JSON files in a folder. Easy to inspect, back up, or clear out manually.
Agent-agnostic
Any script or agent that can write a JSON file can post to Station. Works with Claude Code, Cowork, or your own tools.
Zero dependencies
Uses Python's built-in standard library. Nothing to pip install.
macOS for now
The auto-start uses macOS LaunchAgents. Linux and Windows support is on the roadmap.

Using it with Claude

Station pairs naturally with Claude Code scheduled tasks and Claude Cowork. If you're using Cowork, there's a plugin that handles the inbox posting automatically — your agents get an agent-inbox skill that writes correctly-formatted entries at the end of every run.

If you're rolling your own agents, the JSON format is simple enough to write by hand in a bash heredoc. Full format is in the README.
